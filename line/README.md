# Кейс 3 — клиника косметологии «Линия»

Полный редизайн демо-кейса: лендинг клиники + отдельная страница записи + админка заявок.
Запись — **только на сайте** (форма → localStorage), без Telegram-бота. Бот упомянут
мелкой ссылкой в футере как резервный способ связи, но не как основной CTA.

## Файлы

| Путь | Назначение |
|------|------------|
| `index.html` | лендинг: направления, приём, подготовка/противопоказания, врач, стерильность, цены, FAQ, контакты |
| `book.html` | страница записи — форма (услуга, дата/время, контакты) → сохраняет заявку в `localStorage` |
| `admin/index.html` | админка заявок: статусы, фильтры, заметки, пустые состояния — читает те же данные из `localStorage` |
| `admin/admin.css` | стили админки (отдельная тема, тот же бренд-шрифт) |
| `admin/admin.js` | логика админки: рендер списка, счётчики, смена статуса, демо-гейт |
| `js/bookings.js` | общее хранилище заявок (`localStorage`, ключ `linia_bookings`) — использует и `book.html`, и админка |
| `styles.css` | стили сайта и `book.html` (единая дизайн-система: sage/ivory, Newsreader + Manrope) |
| `images/` | согласованный набор фото Unsplash (clinical-calm), см. `images/CREDITS.md` |

## Как открыть

Простое открытие файла может ограничить `localStorage` в некоторых браузерах —
рекомендуется локальный сервер:

```powershell
cd "c:\Кейсы для фриланса\кейс-3-салон-красоты"
python -m http.server 8000
```

Затем открыть `http://localhost:8000/index.html`.

Или через `serve` (если установлен Node.js):

```powershell
npx --yes serve .
```

## Как протестировать сценарий «запись → админка»

1. Откройте `index.html` (или сразу `book.html`) и нажмите «Записаться на сайте».
2. На странице записи выберите услугу, дату/время, укажите имя и телефон/Telegram,
   отправьте форму — появится экран «Заявка отправлена».
3. Откройте `admin/index.html`. При первом входе — демо-пароль **liniya2026**
   (показан в подсказке под полем, это не настоящая защита, а витрина UI).
4. Только что отправленная заявка сразу видна в списке со статусом «Новая»,
   счётчики наверху обновились.
5. Проверьте действия на карточке: «Подтвердить» → «Выполнено» → «Отменить»,
   поле «Заметка администратора» (сохраняется по уходу с поля), «Удалить».
6. Кнопка «Демо-данные» в панели действий заполняет админку тестовыми заявками,
   если нужно посмотреть список без ручного заполнения формы.
   «Очистить всё» — полностью очищает `localStorage` (с подтверждением).
7. Заявки хранятся в `localStorage` браузера (ключ `linia_bookings`) — доступны
   из любой страницы того же сайта/origin, переживают перезагрузку страницы,
   но не синхронизируются между разными браузерами/устройствами (это демо, не бекенд).

## Под клиента

- Замените телефон, e-mail, адрес и часы работы в `index.html` (`#contacts`) и футере.
- Замените имя и стаж врача в `#doctor`.
- Поменяйте ссылку бота `Keis_My_different_bot` в футере на свою (или уберите строку целиком).
- Смените демо-пароль админки в `admin/admin.js` (`GATE_PASSWORD`) или замените гейт
  на реальную авторизацию, если нужен настоящий бекенд.
- Для «живых» (не только локальных) заявок нужен бекенд или интеграция с ботом
  из `кейс-2-бот-заявок` — сейчас всё хранится только в браузере посетителя.
