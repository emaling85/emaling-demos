Mini App «Сажа» — проба (продукт T3 №3, черновик)

Статика: меню + корзина + отправка заказа.
URL после пуша: https://emaling85.github.io/emaling-demos/miniapp/

Как смотреть
1. В браузере: открой index.html или URL выше — заказ уйдёт ссылкой в @emaling_dev
2. В Telegram: BotFather → Bot Settings → Menu Button / Web App URL = этот URL
   Тогда внутри TG кнопка «Отправить заказ» шлёт данные через WebApp.sendData
   (нужен бот, который принимает web_app_data — следующий шаг)

Это не полноценный продаваемый бот меню. Это проверка UX Mini App для портфолио.
