# Кейс 4 — интернет-магазин «Форзац»

Многостраничный демо-магазин книг: каталог, карточка товара, корзина (localStorage), оформление заказа в Telegram. Чистая статика HTML/CSS/JS — без бэкенда и сборки.

**Бренд:** книжная лавка «Форзац»  
**Пометка:** в футере каждой страницы — «демо-кейс»

## Как открыть локально

Дважды кликните `index.html` или в PowerShell:

```powershell
start "c:\Кейсы для фриланса\кейс-4-книжный\index.html"
```

Либо поднимите простой сервер из папки кейса (удобнее для проверки `localStorage`):

```powershell
cd "c:\Кейсы для фриланса\кейс-4-книжный"
npx --yes serve .
```

## Страницы

| Файл | Что показывает |
|------|----------------|
| `index.html` | Главная: бренд, горизонтальная «полка», выбор лавки, блок доставки |
| `catalog.html` | Сетка из 12 книг, чипы жанров/меток, «В корзину» |
| `book.html?id=…` | Карточка: хлебные крошки, цена, наличие, «для кого», sticky bar на мобиле |
| `cart.html` | Корзина + форма → Telegram (характерная пустая корзина) |
| `about.html` | О лавке, самовывоз/доставка, шаги заказа |

Данные книг: `data/books.js` (серия «Открытая классика», метки `new` / `pick`, наличие).  
Обложки: папка `covers/` (Open Library) + `covers/CREDITS.md`.  
Стили: `styles.css`. Логика: `script.js`.

## UI-фичи витрины

- Серия **«Открытая классика»** — единая рамка, шильдик, латунный корешок
- Реальные обложки из Open Library (офлайн-копии в `covers/`)
- Горизонтальная полка-скролл на главной
- Метки «Новинка» / «Выбор лавки» на карточках
- Фильтры-чипы в каталоге (жанр + метки)
- Страница книги: крупные цена и наличие, блок «Для кого», заметка про самовывоз/доставку
- Sticky-бар «В корзину» на `book.html` (мобильный)
- Trust-strip на главной и развёрнутый блок доставки на about

## Выкладка на Netlify Drop (бесплатно)

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку `кейс-4-книжный` целиком.
3. Получите ссылку вида `https://….netlify.app` — её можно слать заказчику.

Аккаунт Netlify нужен только если хотите закрепить сайт надолго; для разового дропа часто хватает гостевого режима.

## Что показать клиенту за 1 минуту

1. **Главная** — «Форзац», полка-скролл, выбор лавки, блок доставки.
2. **Каталог** — чипы жанров, добавить 1–2 книги (счётчик в шапке).
3. **Карточка** — цена, наличие, sticky «В корзину» на телефоне.
4. **Корзина** — изменить количество → Telegram `t.me/emaling_dev` с текстом заказа.

## Технические заметки

- Корзина в `localStorage` (ключ `forzats-cart`).
- Обложки — CSS/типографика, без внешних картинок и API.
- Заказ: `https://t.me/emaling_dev?text=…` через `encodeURIComponent`.
- Книга без наличия (`inStock: false`) — кнопка неактивна, подсказка в toast.
