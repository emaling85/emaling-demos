# Обложки

Источник изображений: [Open Library Covers API](https://openlibrary.org/dev/docs/api/covers)  
(публичный каталог обложек; файлы скачаны для офлайн-демо на Netlify).

Серия на сайте: **«Открытая классика»** — единое оформление витрины лавки «Форзац»  
(рамка серии, шильдик издания). Сами сканы обложек — из разных исторических изданий в OL,  
сведены в одну полку общим UI.

Тексты произведений — общественное достояние.
