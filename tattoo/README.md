# Кейс 8 — тату-студия «Чернила»

Многостраничный сайт тату-салона в тёмном стиле (референс BARAKA): главная, студия, мастера, портфолио, услуги, отзывы, контакты.
Запись — модалка → `localStorage` (ключ `chernila_bookings`). Без бэкенда и админки.

## Онлайн

https://emaling85.github.io/emaling-demos/tattoo/

## Файлы

| Путь | Назначение |
|------|------------|
| `index.html` | главная |
| `about.html` | студия и клиенты |
| `masters.html` | мастера |
| `portfolio.html` | портфолио с фильтрами |
| `services.html` | услуги и прайс |
| `reviews.html` | отзывы |
| `contacts.html` | контакты + карта |

| `script.js` | меню, FAQ, фильтры, модалка |
| `images/` | фото, см. `CREDITS.md` |

## Как открыть локально

```powershell
cd "c:\Кейсы для фриланса\sites\кейс-8-тату"
python -m http.server 8000
```

Открыть http://localhost:8000/
