# Кейс 5 — сайт кофейни «Сажа»

Демо: витрина specialty-кофейни + **QR-заказ в зале**. Чистая статика HTML/CSS/JS.

**Онлайн:** https://coffesellemaling.netlify.app/  
**Бренд:** кофейня «Сажа»  
**Пометка:** в футере — «демо-кейс»

## User journey (гость)

1. **Стол** — `qr.html?table=N` (скан QR) → подтвердить / сменить стол → «Открыть меню»
2. **Меню** — `menu.html` → объём → «В заказ» → sticky «К заказу»
3. **Корзина** — `order.html` → комментарий → «К оплате»
4. **Оплата** — `pay.html` → демо-кнопка → заказ в `localStorage`
5. **Статус** — `status.html` → понятный статус гостю (Новый / Готовим / Можно забирать)

Витрина (`index.html`, `about.html`, `menu.html`) — про кофейню: атмосфера, зерно, зал, команда. QR-заказ на витрине — вторичный CTA (ghost-кнопка в хедере и внизу), не главный смысл бренда. Ссылка «Заказ со стола» ведёт в шаг 1.

На `menu.html` есть поиск по названию/описанию и переключатель «★ Избранное» (localStorage `sazha_favorites`) — не требуют бэкенда, работают только на клиенте.

**Админка бариста** (`admin.html`) — мелкая ссылка «Вход для бариста» в футере витрины. Умеет:
- список заказов: стол, время, состав с объёмами, сумма, статус;
- статусы: Новый → Готовим → Можно забирать → Закрыт;
- кнопки: «В работу», «К выдаче», «Закрыть»;
- фильтр: активные / все;
- данные из `localStorage` (`sazha_orders`).

Старый `barista.html` редиректит на `admin.html`.

## Как открыть локально

```powershell
start "c:\Кейсы для фриланса\кейс-5-кофейня\index.html"
```

Или:


## Технические заметки

- Корзина / стол / заказы: `localStorage` (`sazha_cart`, `sazha_table`, `sazha_orders`).
- Стол: `?table=` из URL читается **один раз** при загрузке; дальше — `localStorage`.
- Размеры напитков: `sizes[]` в `menu.js` + cup SVG / S·M·L.

## Мини-тест: смена стола

1. `qr.html?table=2` — бейджи **2**.
2. Select → стол **7** — бейджи и URL `?table=7`.
3. «Открыть меню» → `menu.html?table=7`.
